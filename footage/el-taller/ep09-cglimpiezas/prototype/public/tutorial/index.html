Tu Mercado Pago

Para que el cliente pague desde su cotización y la plata llegue directo a tu cuenta.

…
  1. Entra a mercadopago.cl/developers con tu cuenta de Mercado Pago (la misma donde recibes plata).
  2. Crear aplicación → nombre "CG Limpiezas" → tipo: pagos online → producto: Checkout Pro.
  3. Dentro de la aplicación → Credenciales de producción → activa las credenciales (te pide el rubro y la web: pon la de tu cotizador).
  4. Copia el Access Token (empieza con APP_USR-).
  5. En la misma aplicación → Webhooks → URL: evento Order → Guardar. Copia la clave secreta que aparece.
  6. Esas dos cosas (el Access Token y la clave secreta) se pegan en tu computador, en el panel de El Taller, una sola vez. Nunca por WhatsApp ni por correo.

Mientras no esté conectado, el pago dice "Pago de prueba" y no se cobra nada.
